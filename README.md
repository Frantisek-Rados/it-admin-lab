# IT Admin Lab

Praktické laboratórne prostredie a poznámky zo samovzdelávania v oblasti IT administrácie.
Cieľ: precvičiť si reálne scenáre správy systémov, sietí a serverov, ktoré sa používajú v praxi.

## Čo tu nájdeš

- Linux server (Ubuntu Server) – inštalácia, konfigurácia, služby
- Windows Server – Active Directory, používatelia, skupiny, GPO
- Počítačové siete – TCP/IP, DNS, DHCP, VLAN, firewall
- Virtualizácia – VirtualBox, VMware, Proxmox
- Docker – kontajnery, základné nasadenie
- Monitoring a zálohovanie
- PowerShell a Bash skripty
- Bezpečnosť – základy hardeningu, firewall, SSH kľúče
