# Deň 1 — Linux základy

## Čo som sa naučil
- Linux je open-source OS, beží na serveroch, ovláda sa cez terminál
- Terminál (Bash) = textové rozhranie
- Štruktúra: `/` (root), `/home/frantisek` (môj priečinok), `~` (skratka)
- Absolútna cesta začína od `/`, relatívna od aktuálneho priečinka

## Príkazy
- `pwd` — kde som
- `ls` / `ls -la` — zoznam súborov
- `cd` — zmena priečinka
- `mkdir` — vytvor priečinok
- `touch` — vytvor súbor
- `cp` — kopíruj
- `mv` — presuň / premenuj
- `rm` / `rm -r` — zmaž
- `cat` — zobraz obsah
- `echo "text" > subor` — zapíš do súboru

## Praktické cvičenie
- Vytvoril som priečinok `lab1`
- Vytvoril som súbor `poznamka.txt`
- Zapísal som text do súboru
- Presunul som súbor do `backup/`
- Skopíroval som súbor
- Zmazal som celý priečinok
